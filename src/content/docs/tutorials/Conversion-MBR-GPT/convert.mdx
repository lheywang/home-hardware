Pour convertir un disque MBR en GPT : 

<Step step={1} title="Ouvrir DiskPart" tag="DiskPart" open>

    - Sur le menus d'installation, lors de la sélection des disques, maintenez la touche maj / Shift enfoncée et appuyez sur f10
    - Cela ouvre un invite de commande. Tapez Diskpart, puis entrer

</Step>


<Step step={2} title="DiskPart" tag="DiskPart" open>

    ```bash
    list disk
    select disk <remplacer par le numéro souhaité dans la liste précédente>
    clean
    convert GPT
    ```

</Step>

Et, c'est tout !
