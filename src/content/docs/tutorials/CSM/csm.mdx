Si votre ordinateur détecte vos disques de stockage dans le BIOS, mais que vous n’avez aucun disque disponible dans le menu "Boot Priority" ou "Séquence de démarrage", ne vous inquiétez pas, c’est un problème récurrent.

<Step step={1} title="Aller dans le bios" tag="BIOS" open>

    - Juste après avoir démarré votre PC, appuyez sur la touche suivante : 

    <Tabs syncKey="brand">
        <TabItem label="MSI">
            - Suppr (Del)
            - F11
        </TabItem>
        <TabItem label="Asus">
            - Suppr (Del)
            - F2
        </TabItem>
        <TabItem label="Gigabyte">
            - Suppr (Del)
            - F12
        </TabItem>
        <TabItem label="Asrock">
            - Suppr (Del)
            - F2
        </TabItem>
        <TabItem label="HP">
            - Echap
            - F10
        </TabItem>
        <TabItem label="Dell">
            - F2
        </TabItem>
    </Tabs>

</Step>

<Step step={2} title="Ouvrir le menu avancé" tag="BIOS" open>

    - Allez ensuite dans le menu avancé : 

    <Tabs syncKey="brand">
        <TabItem label="MSI">
            - F7
        </TabItem>
        <TabItem label="Asus">
            - F7
        </TabItem>
        <TabItem label="Gigabyte">
            - F2
        </TabItem>
        <TabItem label="Asrock">
            - F6
        </TabItem>
        <TabItem label="HP">
            - Ctrl + F10
        </TabItem>
        <TabItem label="Dell">
            - ??
        </TabItem>
    </Tabs>

</Step>

<Step step={3} title="Activer le CSM" tag="CSM" open>

    - Une fois dans le mode avancé, il faudra trouver le menu pour activer le support CSM :

    <Tabs syncKey="brand">
        <TabItem label="MSI">
            - Settings -> Advanced -> OS Configuration.
        </TabItem>
        <TabItem label="Asus">
            - BOOT (démarrage) et trouver l'onglet CSM.
        </TabItem>
        <TabItem label="Gigabyte">
            - BOOT (démarrage) et trouver l'onglet CSM.
        </TabItem>
        <TabItem label="Asrock">
            - BOOT (démarrage) et trouver l'onglet CSM.
        </TabItem>
        <TabItem label="HP">
            - ??
        </TabItem>
        <TabItem label="Dell">
            - ??
        </TabItem>
    </Tabs>

    Puis l'activer : 

    <Tabs syncKey="brand">
        <TabItem label="MSI">
            - passer d'UEFI -> à CSM.
        </TabItem>
        <TabItem label="Asus">
            - passer de Disabled (désactivé) -> à Enabled (activé).
        </TabItem>
        <TabItem label="Gigabyte">
            - passer de Disabled (désactivé) -> à Enabled (activé).
        </TabItem>
        <TabItem label="Asrock">
            - passer de Disabled (désactivé) -> à Enabled (activé).
        </TabItem>
        <TabItem label="HP">
            - ??
        </TabItem>
        <TabItem label="Dell">
            - ??
        </TabItem>
    </Tabs>

</Step>

<Step step={4} title="Sauvegarder et quitter" tag="SAVE" open>

    L’option CSM étant activée, il faut enregistrer cette modification : faire F10 puis Save and Exit (sauvegarder et quitter).

    L'ordinateur va donc redémarrer et les disques seront disponibles dans la section Boot Priority. Si l'operating system (OS) n'est pas encore installé sur les disques présents. Veuillez mettre la clé USB bootable pour pouvoir commencer l'installation de l'OS avant le démarrage de celui-ci.

</Step>
